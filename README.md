# Prueba Técnica - GestorFPQRS

Cordial saludo, la maquetación de GestorFPQRS se realizó de forma estática; no se tuvieron en cuenta tecnologías como React, Angular, Vue, ni ningún preprocesador CSS ni procesador de HTML. Por tal motivo, la maquetación que se presenta en este momento cubre con la petición dicha por el remitente, donde se requiere ver la forma de cómo se maqueta o se estructura un contenido visual a código web.

De tal forma, cabe decir que hay archivos HTML que cuentan con bastantes líneas debido al tiempo y a la búsqueda de la perfección visual a la hora de maquetar y estructurar el contenido; no se logró realizar una adaptación más dinámica con JavaScript/jQuery en su totalidad, aunque sí hay una sección donde se consume información de un archivo JavaScript.

## Tecnologías Utilizadas

Sobre las tecnologías utilizadas, se realizó el proyecto con lo acordado por el remitente, donde para la estructura del contenido se usó HTML Semántico y para el diseño web se usaron clases de la librería Bootstrap, cumpliendo con el patrón de menos código CSS y más clases CSS. Es cierto que para que el diseño de GestorFPQRS se pareciera tal cual a lo acordado se tuvo que agregar código CSS propio para ajustar colores, tamaños y fuentes. Para la interacción y la manipulación del DOM usamos jQuery/JavaScript.

## Instrucciones de Ejecución

Para el proceso de maquetación y programación del proyecto GestorFPQRS se agregaron las librerías de Bootstrap CSS, JavaScript y jQuery desde el CDN para una mayor velocidad a la hora de cargar los recursos. Por tal motivo, para la ejecución del código por mi parte he decidido subirlo a un alojamiento gratuito como GitHub Pages ( [Enlace a Demo](https://juanmoncayo55.github.io/gestor-fpqrs/) ).

Sin embargo, si como reclutador tienes experiencia en desarrollo web, te indico que puedes abrir el proyecto en Visual Studio Code y ejecutar el index.html con el Live Server de VS Code, dando clic secundario dentro del archivo index.html y cliqueando en "Open with Live Server"; en la dirección http://127.0.0.1:5500/ por defecto ahí podrás ver el DEMO. 

Así como también, si tienes Node.js y NPM en tu máquina, puedes instalar el paquete http-server con el comando "npm install -g http-server" y, después de instalar este paquete, entras en la carpeta del proyecto y ejecutas el comando "http-server" en la consola para ver la dirección del proyecto.
